# PageDrop {{version}}

## Highlights

- **PageDrop now runs on Linux.** Each release ships a portable `x86_64` AppImage alongside the Windows installer.
- **AppImage managers work out of the box.** The AppImage carries update information and a matching `.zsync` file, so Gear Lever and AppImageUpdate can install and update PageDrop for you.

## Added

- Linux AppImage builds with SHA-256 checksums and zsync delta updates.
- AppStream metadata, so app managers and software centres show PageDrop's name, description, licence, and links.
- The About dialog now shows the current version.

## Changed

- Windows and Linux builds are tested and published together in one release.

## Fixed

- PDF viewer pages failed to draw because of mismatched rectangle types.
- The onboarding, preferences, and update dialogs can now be resized.
- Upgrading with the Windows installer now removes stale package metadata from the previous version.

## Known issues

- The AppImage is `x86_64` only and needs glibc 2.35 or newer (Ubuntu 22.04 or later, or an equivalent distribution).
- The in-app updater remains Windows-only. On Linux, update through Gear Lever or AppImageUpdate.

## Downloads and installation

- **Windows:** download `PageDrop-{{version}}-Setup.exe` and run the installer.
- **Linux:** download `PageDrop-{{version}}-x86_64.AppImage`, make it executable (`chmod +x`), and run it.
- **AppImage managers:** Gear Lever can integrate the AppImage. AppImageUpdate can apply zsync updates; each release also includes the matching `.zsync` file.
