# PageDrop documentation

PageDrop is a free, open-source PDF desktop app: thumbnail grid, multi-tab editing, drag pages into your file manager, merge, image→PDF, and a local Tools hub. Edits never overwrite the original file.

| [User guide](user-guide.md) | Open, select, edit, drag-out, Merge, Create PDF, preferences, shortcuts |
| [Tools](tools.md) | Tools hub catalogue, optional backends, result UX |
| [Development](development.md) | Run from source, layout, stack, tests, product constraints |
| [Building](building.md) | PyInstaller onefile, smoke checks, Windows installer, release checklist |
| [Architecture](architecture.md) | Layers, edit model, drag mime, jobs, capabilities, PyMuPDF locking |
| [Licensing](licensing.md) | Source MIT vs binary redistribution (PyQt6 / PyMuPDF / Qt) |

Start with the [user guide](user-guide.md) if you are using the app, or [development](development.md) if you are hacking on it.
